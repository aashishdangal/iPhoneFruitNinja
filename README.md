# iPhone Fruit Slicer 🍎📱

Turn your iPhone into a motion controller for a fruit-slicing game on your Mac.

Built with Unity and a companion SwiftUI app, iPhone Fruit Slicer uses your phone’s tilt and acceleration to control an on-screen blade over local Wi-Fi. Move your phone, slice flying fruits, build combos, and avoid falling bombs.

The game features a 3D Nepali khukuri as its blade, alongside Nepali background music.

## Core Features

- **iPhone motion controls:** Combine tilt and acceleration to move the blade.
- **Wireless connection:** Send motion data from iPhone to Unity over local Wi-Fi using UDP.
- **Calibration and smoothing:** Set a comfortable neutral position and adjust responsiveness.
- **Mouse mode:** Play and test without connecting a phone.
- **Fruit-slicing gameplay:** Slice six fruit types, earn multi-fruit combos, and protect your three lives.
- **Bomb encounters:** Avoid falling bombs with whistles, metallic impacts, explosions, and white-flash effects.
- **3D presentation:** An animated khukuri, fruit pieces, and contextual sound effects.

## Project Goal

Explore how an iPhone can act as a responsive physical controller for a game running on a Mac.

This personal project combines mobile motion sensors, wireless communication, and Unity gameplay. Future work includes a Mac webcam background and camera-assisted tracking.
